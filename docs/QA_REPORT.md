# سجل الفحوص المحلية

التاريخ: 9 سبتمبر 2026. الحزمة: 12.5.0.

## النتيجة

نجح 91 اختبارًا سريعًا، و14 مجموعة اختبار تكامل على PostgreSQL محلي عبر PGlite 0.5.8. لم يُنفذ أي تغيير على مشروع Supabase منشور.

| حماية التثبيت | رفض التنفيذ فوق نظام موجود مع بقاء بياناته؛ عمل البصمة عند وجود pgcrypto في public أو extensions | نجح |

فحص الصياغة شمل 68 ملف JavaScript وTypeScript وملفات اختبار، دون أخطاء صياغة. فحص CSS شمل 1062 قاعدة دون أخطاء تحليل. هذه فحوص مصدر وملفات؛ لا تعني اختبار شكل الواجهة في متصفح حقيقي.

## حدود التحقق

اختبار التكامل يشغل محرك PostgreSQL فعليًا داخل PGlite، ويستخدم بدائل صغيرة لجداول Auth وStorage وأدوار المنصة. تشغيل منطق المساعد محليًا يمر بالاستعلامات والصلاحيات والمعاملات الفعلية، بينما طبقة HTTP وAuth الخارجية وGemini غير مستدعاة في هذا الاختبار.

لم يتوفر متصفح لفحص العرض المرئي أو التفاعل على أجهزة فعلية. كما لم تُختبر شبكة Supabase المنشورة أو إنشاء مستخدم Auth عبر الشبكة أو رفع المرفقات إلى Storage فعلي أو استعادة ZIP كبيرة أو استجابة Gemini الحية. لا تمثل نتائج الفحوص ضمانًا بخلو كل بيئة وكل حالة من الأخطاء.

## فحص التشغيل بعد الإعداد

1. نفذ الملف على مشروع جديد فارغ، ثم أنشئ المدير واضبط الاتصال وانشر الوظائف وفق README.md.
2. اختبر الدخول والأجهزة والحسابات بأدوار مختلفة، وحالة النظام وسجلات الدخول.
3. افتح الدخول واللوحة والسندات والمساعد على كمبيوتر وهاتف؛ راجع الخط والتمرير والاختيارات والطباعة.
4. ارفع صورة قابلة للضغط وملفًا غير قابل للضغط، ثم تحقق من العرض والتحميل.
5. أنشئ نسخة V4 تشمل الملفات، واختبر الدمج والمطابقة في مشروع تجريبي يحفظ مراجع مستخدمي Auth، ثم طابق الأرصدة والمخزون والمرفقات.
6. اطلب من المساعد قراءة ثم إضافة مسودة ثم تعديلها ثم إجراء مالي؛ راجع كل اقتراح قبل التأكيد واختبر رفض الدور غير المسموح.

ملف SQL مخصص للتثبيت الجديد، وليس ترقية لقاعدة قائمة. لم تحذف هذه الحزمة بيانات الاستضافة ولم تغيرها.

## إعادة الفحوص

من جذر المشروع باستخدام Node.js 24:

```bash
node --test --test-concurrency=2 tests/*.test.mjs
```

قاعدة الاختبار المستقلة:

```bash
cd tests/integration
npm ci
npm test
```

يبين كل إخفاق في اختبار التكامل المرحلة والسبب ورمز الخطأ. يعتمد نجاح بيئة Supabase المنشورة أيضًا على ضبط Auth وStorage والأسرار ونشر الوظائف.
